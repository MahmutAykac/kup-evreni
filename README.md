# Küp Evreni

Tarayıcıda oynanan mini oyun platformu: Pizza Kulesi Tycoon, Evcil Hayvan Simülatörü: Gezegenler, Kaçış Parkuru: Çılgın Fabrika, Ada Hayatta Kalma: Tekne Kazası, Klavye Koşusu: +1 Hız, Kasaba Hayatı RP, Limonata Standı, Küp Arena, Daha Fazla Köpük!

Bilgisayarda ve telefonda çalışır. Hesaplar (kullanıcı adı + şifre), Robux, avatar, rozetler ve oyun ilerlemesi bulutta (Supabase) saklanır; her cihazdan aynı hesapla girilir. Oyun içi ilerleme de hesaba bağlı olarak bulutta saklanır.
